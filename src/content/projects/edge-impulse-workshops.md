I wrote these tutorials for IEEE workshops using Edge Impulse Studio and the Arduino Nano 33 BLE Sense.

## What the tutorials cover
1. Getting started and collecting data from a phone or device.
2. Designing an impulse, choosing processing and learning blocks, and generating features.
3. Training, testing, and deploying the model to the board.

Each part has screenshots, instructions, and code examples. The materials are available under CC BY 4.0; the repo has the attribution instructions.
